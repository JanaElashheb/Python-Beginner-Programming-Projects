**Python Beginner Programming Projects**
A collection of beginner Python programs created to practice fundamental programming concepts, mathematical calculations, problem-solving, and basic user interaction.

**About the Project**
These projects were created while learning the fundamentals of Python programming. Each program focuses on a specific concept or small programming problem, providing practice with variables, input and output, calculations, conditionals, and basic problem-solving.

**Projects**

**Concepts Practiced**
- Variables and data types
- User input and output

- Conditional statements
- Basic mathematical problem-solving
- Working with numbers and formulas
